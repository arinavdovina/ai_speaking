# Speaking Mechanics Lab — v2

Статический конструктор промптов для speaking-материалов. Сохраняет методическую основу исходного проекта: 30 сценариев, 20 механик, PRINT / LIVE. Для генерации самого учебного материала перенесите промпт в выбранный ИИ-сервис.

## Публикация на GitHub Pages

1. Сохраните резервную копию текущего репозитория.
2. Загрузите содержимое этой папки в корень репозитория `confa_speak`: `index.html`, `styles.css`, `app.js`, `.nojekyll`. Важно: index.html должен лежать в корне, а не во вложенной папке.
3. В GitHub откройте Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите ветку с файлами (обычно main) и папку / (root), нажмите Save.
5. Дождитесь завершения публикации. Адрес существующего репозитория останется https://m2010477-prog.github.io/confa_speak/.

Сборка, npm и внешние зависимости не нужны. Можно открыть index.html напрямую, но работа буфера обмена зависит от браузера; для полной проверки используйте HTTPS или localhost.

## Что изменено

- Навигация по девяти шагам, спокойная зелёная палитра, улучшенный фокус клавиатуры и размер кнопок.
- Ясное объяснение: продукт создаёт промпт, а не готовое занятие.
- Автосохранение настроек в localStorage этого браузера; данные не отправляются на сервер.
- Восстановление после перезагрузки и импорт JSON из новой и исходной версии.
- Проверка полей и известных значений при импорте; ошибочный файл не применяется.
- Перед сборкой обязательны тема, механики, цель и задача слушателя.
- При превышении четырёх механик выводится объяснение.
- Копирование и экспорт текста доступны после сборки; изменение настроек требует повторной сборки.
- Сброс черновика требует подтверждения.
- Исправлена несуществующая рекомендованная механика Respond to an Objection: заменена на Repair the Conversation.
- Anti-guessing обозначен как ручная проверка, а индикаторы отделены от оценки готового материала.
- Сообщения об ошибках копирования и недоступности автосохранения.

## Проверено

Синтаксис app.js; загрузка страницы без ошибок JavaScript; валидация пустой формы; демо и сборка LIVE-промпта; восстановление темы после перезагрузки. Полный цикл импорта, скачивания файлов и мобильная вёрстка ещё не проверены в браузере.

Исходный опубликованный сайт и GitHub-репозиторий не изменены.

## Обновление: красный / бежевый и возрастные рекомендации

Основные цвета: глубокий красный #74252a, акцентный красный #b32f32, бежевый фон #f4eade.

После выбора Kids / Teens / Adults автоматически обновляются сценарии, механики, речевые функции, источники сложности, задачи слушателя, рекомендации CEFR и параметры PRINT / LIVE. У каждого списка есть «Показать все» и «Только по возрасту». Язык и свободный контент остаются на выбор преподавателя; PRINT и LIVE доступны в любом возрасте.

Возрастная фильтрация — авторские стартовые рекомендации, а не диагностика возможностей ученика. CEFR не определяется возрастом. Выбранный через полный список вариант сохраняется видимым после сворачивания фильтра. При смене возраста механики и цели сбрасываются, сценарий переключается на первый для новой группы, сложность и задача слушателя возвращаются к базовым значениям, поддержка и параметры носителя обновляются; тема и текстовый контекст сохраняются.

Проверено в браузере: Kids — 8 механик, полный список — 20; полный список сценариев — 30; смена Adults → Kids восстанавливает A2 и High; ошибок JavaScript не обнаружено.

## Случайный промпт: библиотека из 90 решений

Кнопка «Случайный промпт» выбирает готовое сочетание для текущего возраста и сразу собирает промпт. По 30 решений для Kids / Teens / Adults: по три конкретных ситуации на каждый из десяти возрастных сценариев. У решения есть тема, CEFR, речевые цели, механики, задача слушателя, контекст, поддержка и формат PRINT или LIVE. Текущий язык сохраняется; остальные настройки заменяются пресетом. Их можно редактировать после выбора.

Кнопка «Ещё случайный» доступна у результата. Каждый набор перемешивается и выдаётся без повторов в пределах 30 решений. После исчерпания начинается новый круг; первое решение нового круга отличается от последнего предыдущего. Очередь каждого возраста хранится отдельно в localStorage браузера. Если хранилище недоступно, очередь работает только до перезагрузки.

Библиотека находится в `random-library.js`; обязательно загрузите этот файл вместе с index.html, styles.css и app.js. Изменяйте существующие записи или добавляйте новые с уникальными id, используя известные значения механик и параметров конструктора.

Проверено: все 90 решений собирают промпт; 30 уникальных выдач на каждую возрастную группу; выбранный Deutsch сохраняется; очередь продолжается после перезагрузки. Сам учебный материал по-прежнему создаётся во внешнем ИИ-сервисе по полученному промпту.
