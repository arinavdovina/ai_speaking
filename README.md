# Speaking Mechanics Lab — v2

Статический конструктор промптов для speaking-материалов. Сохраняет методическую основу исходного проекта: 30 сценариев, 20 механик, PRINT / LIVE. Для генерации самого учебного материала перенесите промпт в выбранный ИИ-сервис.

## Публикация на GitHub Pages

1. Сохраните резервную копию текущего репозитория.
2. Загрузите содержимое этой папки в корень репозитория `confa_speak`: `index.html`, `styles.css`, `app.js`, `.nojekyll`. Важно: index.html должен лежать в корне, а не во вложенной папке.
3. В GitHub откройте Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите ветку с файлами (обычно main) и папку / (root), нажмите Save.
5. Дождитесь завершения публикации. Адрес существующего репозитория останется https://m2010477-prog.github.io/confa_speak/.

Сборка, npm и внешние зависимости не нужны. Можно открыть index.html напрямую, но работа буфера обмена зависит от браузера; для полной проверки используйте HTTPS или localhost.

## Что изменено

- Навигация по девяти шагам, спокойная зелёная палитра, улучшенный фокус клавиатуры и размер кнопок.
- Ясное объяснение: продукт создаёт промпт, а не готовое занятие.
- Автосохранение настроек в localStorage этого браузера; данные не отправляются на сервер.
- Восстановление после перезагрузки и импорт JSON из новой и исходной версии.
- Проверка полей и известных значений при импорте; ошибочный файл не применяется.
- Перед сборкой обязательны тема, механики, цель и задача слушателя.
- При превышении четырёх механик выводится объяснение.
- Копирование и экспорт текста доступны после сборки; изменение настроек требует повторной сборки.
- Сброс черновика требует подтверждения.
- Исправлена несуществующая рекомендованная механика Respond to an Objection: заменена на Repair the Conversation.
- Anti-guessing обозначен как ручная проверка, а индикаторы отделены от оценки готового материала.
- Сообщения об ошибках копирования и недоступности автосохранения.

## Проверено

Синтаксис app.js; загрузка страницы без ошибок JavaScript; валидация пустой формы; демо и сборка LIVE-промпта; восстановление темы после перезагрузки. Полный цикл импорта, скачивания файлов и мобильная вёрстка ещё не проверены в браузере.

Исходный опубликованный сайт и GitHub-репозиторий не изменены.
